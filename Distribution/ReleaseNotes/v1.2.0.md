# MacChannel 1.2.0

这是首个内置应用更新功能的版本。从 v1.1.10 升级时，需要最后一次从官方
GitHub Release 下载公证 DMG，并把 MacChannel 拖入“应用程序”完成覆盖安装。
从 v1.2.0 开始，后续版本可以在应用内检查和安装。

## 更新内容

- 在设置中显示当前版本和构建号。
- 每天在后台检查一次更新，不因无更新或临时网络问题打断使用。
- 由用户主动查看、下载并安装更新，不进行静默强制安装。
- 有传输正在进行时，安装可以准备就绪，但重新启动会延迟到传输结束。
- 改善菜单栏图标在不同外观和背景下的对比度。

## 安装说明

如果当前安装的是 v1.1.10，请打开本次发布的 `MacChannel.dmg`，把 MacChannel
拖入“应用程序”并选择“替换”。设置、身份、配对与传输历史保存在 App 包之外；
本次覆盖安装不会主动删除这些数据。此后发现新版本时，可以从设置或菜单栏查看，
并由你决定何时安装。
