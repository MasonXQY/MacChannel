# MacChannel v1.1.0 Release Acceptance Plan

**Goal:** Publish a universal, Developer ID signed, notarized and stapled MacChannel v1.1.0 DMG that succeeds on two Macs and converges membership on a third Mac.

## Task 1: Clean release candidate

- Require clean committed HEAD, version `1.1.0` build `2`, fixed production endpoint, universal arm64/x86_64 app and WebRTC framework.
- Run all Swift tests, Go race/vet, integration, privacy, shell, build, launch and no-Tailscale contracts.
- Record exact commit, commands, counts and UTC timestamps.

## Task 2: Upgrade preservation

- Install v1.0.1, record identity public-key digest, trust peers, receive directory, history, TransferID and ResumeMap.
- Upgrade in place to v1.1.0 and prove every value is preserved while legacy network settings disappear.

## Task 3: Apple distribution

- Build with the installed Developer ID Application identity and hardened runtime/timestamp.
- Submit with the stored notary profile, require Accepted, staple app/DMG where applicable, and require strict codesign, stapler and Gatekeeper acceptance.
- Produce manifest with SHA-256, commit, version/build and Team ID.

## Task 4: Two/three-real-Mac matrix

- Re-download the public DMG independently on A, B and C; verify identical digest and install without Xcode or security exceptions.
- Pair A-B, add C through B, prove A/B/C all see and can target each other, then verify removal convergence.
- Test same Wi-Fi, different Wi-Fi, phone hotspot and forced TURN; transfer file, multi-file, folder, Unicode, duplicate names and at least 1 GiB.
- Interrupt network/app mid-transfer and prove resume plus final SHA-256 equality.

## Task 5: Public GitHub release

- Tag the accepted commit `v1.1.0`, publish DMG, manifest and concise release notes.
- Verify `releases/latest`, download artifacts to a fresh directory, verify hashes, signature, notarization and one final launch/transfer.
- Do not announce completion until the public artifact, official service, and real-Mac matrix all pass.
